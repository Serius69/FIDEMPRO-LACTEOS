¿Qué es el Análisis de Demanda?

Este análisis examina los patrones de consumo de agua durante el período simulado, identificando tendencias, variaciones y comportamientos anómalos que pueden afectar la gestión del sistema de distribución.

Utiliza estos datos para: Planificar capacidades, optimizar inventarios, detectar problemas en la red y mejorar la eficiencia operativa.

Validación Completa
¿Qué es el Análisis de Tres Líneas?

Este es el método más robusto para validar la calidad de una simulación de demanda. Compara tres conjuntos de datos clave para determinar si el modelo es confiable para tomar decisiones operativas.

Línea Azul - Histórica Real
Datos reales de consumo del pasado. Esta es la "verdad de referencia" que sabemos que ocurrió.
Línea Roja - Proyección Futura
Predicción matemática basada en tendencias históricas. Muestra hacia dónde "debería" ir la demanda.
Línea Verde - Simulación
Resultado de nuestro modelo de simulación. Debe estar entre las otras dos líneas para ser válida.
Criterios de Validación:
Buena validación: Las tres líneas siguen patrones similares
Simulación entre límites: Verde entre azul y roja
Tendencias coherentes: Misma dirección de cambio
Variabilidad realista: Fluctuaciones similares

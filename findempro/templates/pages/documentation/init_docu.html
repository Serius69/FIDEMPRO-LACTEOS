🔍 Identificación de Distribuciones de Probabilidad

Metodología técnica para identificar las distribuciones que mejor modelan la demanda de productos lácteos en FINDEMPRO

❓ Pregunta de Investigación

¿Cómo se identificaron las distribuciones y sus respectivas ecuaciones en FINDEMPRO LÁCTEOS?

🔬 Metodología de Identificación

1

Recolección y Preparación de Datos

Se recopilan datos históricos de ventas de productos lácteos con un mínimo de 90 días de historia, aplicando filtros de calidad y normalización.

def preparar_datos_lacteos(producto_codigo, dias=90):
    datos = obtener_ventas_historicas(producto_codigo, dias)
    datos_limpios = filtrar_outliers(datos)
    datos_normalizados = aplicar_factores_estacionales(datos_limpios)
    return datos_normalizados
2

Análisis Estadístico Exploratorio

Se calculan estadísticas descriptivas para identificar características clave de la distribución:

  • Medidas de tendencia central: Media, mediana, moda
  • Medidas de dispersión: Varianza, desviación estándar, coeficiente de variación
  • Medidas de forma: Asimetría (skewness) y curtosis
  • Análisis de percentiles: Q1, Q3, rango intercuartílico
3

Pruebas de Bondad de Ajuste

Se ejecutan múltiples pruebas estadísticas para evaluar qué distribución se ajusta mejor:

Pruebas Aplicadas:
  • Kolmogorov-Smirnov
  • Anderson-Darling
  • Cramér-von Mises
  • Shapiro-Wilk (para normalidad)
Criterios de Información:
  • AIC (Akaike Information Criterion)
  • BIC (Bayesian Information Criterion)
  • Log-likelihood
  • R² ajustado
4

Selección Automática de la Mejor Distribución

El sistema utiliza un algoritmo de selección que combina múltiples criterios:

Score = w₁×(1-p_valor_KS) + w₂×AIC_normalizado + w₃×BIC_normalizado

donde: w₁=0.4, w₂=0.3, w₃=0.3

💻 Algoritmo de Implementación


class IdentificadorDistribucionLacteos:
    def __init__(self):
        self.distribuciones_candidatas = [
            ('normal', stats.norm),
            ('lognormal', stats.lognorm),
            ('gamma', stats.gamma),
            ('exponencial', stats.expon),
            ('weibull', stats.weibull_min)
        ]
        
        self.criterios_categoria = {
            'perecedero_diario': {'preferida': 'normal', 'tolerancia': 0.03},
            'semi_perecedero': {'preferida': 'lognormal', 'tolerancia': 0.04},
            'queso_fresco': {'preferida': 'gamma', 'tolerancia': 0.05}
        }
    
    def identificar_distribucion(self, datos, categoria_producto):
        """Identifica la mejor distribución para un producto lácteo"""
        
        # 1. Análisis descriptivo
        estadisticas = self.calcular_estadisticas(datos)
        
        # 2. Pre-filtrado por categoría
        distribuciones_evaluadas = self.prefiltrar_por_categoria(categoria_producto)
        
        # 3. Ajuste y evaluación
        resultados = []
        for nombre, distribucion in distribuciones_evaluadas:
            # Estimación de parámetros
            parametros = self.estimar_parametros(datos, distribucion)
            
            # Pruebas de bondad
            ks_stat, ks_p = stats.kstest(datos, 
                lambda x: distribucion.cdf(x, *parametros))
            
            # Criterios de información
            aic = self.calcular_aic(datos, distribucion, parametros)
            bic = self.calcular_bic(datos, distribucion, parametros)
            
            # Evaluación específica para lácteos
            score = self.evaluar_ajuste_lacteos(
                ks_stat, ks_p, aic, bic, categoria_producto
            )
            
            resultados.append({
                'distribucion': nombre,
                'parametros': parametros,
                'ks_statistic': ks_stat,
                'ks_p_value': ks_p,
                'aic': aic,
                'bic': bic,
                'score': score
            })
        
        # 4. Selección de la mejor
        mejor = min(resultados, key=lambda x: x['score'])
        
        # 5. Validación final
        if self.validar_seleccion_lacteos(mejor, categoria_producto):
            return mejor
        else:
            return self.seleccion_por_defecto(categoria_producto)

Sistema Integrado de Simulación de Demanda para Productos Lácteos

📥 Módulo de Captura de Datos

Recopila automáticamente datos de ventas, inventarios y factores externos específicos de productos lácteos.

Características:
  • Integración con sistema de ventas en tiempo real
  • Captura de factores estacionales
  • Registro de datos de temperatura ambiente
  • Detección automática de promociones y eventos
def capturar_demanda_lacteos(producto, fecha_inicio, fecha_fin):
    datos = {
        'ventas': obtener_ventas(producto, fecha_inicio, fecha_fin),
        'temperatura': obtener_temperatura_ambiente(fecha_inicio, fecha_fin),
        'promociones': obtener_promociones_activas(producto, fecha_inicio, fecha_fin),
        'festividades': obtener_festividades(fecha_inicio, fecha_fin),
        'stock_disponible': obtener_inventario_historico(producto)
    }
    return procesar_datos_lacteos(datos)

🧠 Motor de Análisis Estadístico

Procesa los datos históricos aplicando técnicas estadísticas avanzadas específicas para productos lácteos.

Funcionalidades:
  • Análisis de tendencias y estacionalidad
  • Detección de outliers y datos anómalos
  • Correlación con factores externos
  • Segmentación por categoría de producto
class MotorAnalisisLacteos:
    def analizar_demanda(self, datos_producto):
        # Análisis específico por categoría
        categoria = self.clasificar_producto(datos_producto.producto)
        
        if categoria == 'perecedero_diario':
            return self.analisis_perecedero(datos_producto)
        elif categoria == 'semi_perecedero':
            return self.analisis_semi_perecedero(datos_producto)
        
        return self.analisis_general(datos_producto)

🎲 Generador de Modelos Estocásticos

Crea modelos de simulación basados en las distribuciones identificadas, optimizados para cada tipo de producto lácteo.

Tipos de Modelos:
  • Modelos Normales: Para leche fresca y productos básicos
  • Modelos Log-Normales: Para yogurt y postres
  • Modelos Gamma: Para quesos y productos especiales
  • Modelos Híbridos: Para productos estacionales

🎯 Simulador de Escenarios

Ejecuta simulaciones Monte Carlo considerando múltiples factores específicos del negocio lácteo.

Escenarios Simulados:
  • Demanda normal vs picos estacionales
  • Efectos de promociones y descuentos
  • Impacto de cambios de temperatura
  • Variaciones por días de la semana

🥛 Factores Específicos Considerados para Productos Lácteos

🌡️ Temperatura Ambiente

Impacta directamente en la demanda de productos como helados y bebidas frías

📅 Estacionalidad

Variaciones por época del año, especialmente en productos estacionales

⏰ Perecibilidad

Factor: 0.3 - 1.0
🎉 Eventos Especiales

Factor: 1.2 - 3.0
🏫 Período Escolar

💰 Promociones

💻 Implementación Técnica del Generador


class GeneradorModelosLacteos:
    def __init__(self):
        self.factores_lacteos = {
            'temperatura': FactorTemperatura(),
            'estacionalidad': FactorEstacionalidad(),
            'perecibilidad': FactorPerecibilidad(),
            'eventos': FactorEventosEspeciales(),
            'promociones': FactorPromociones()
        }
    
    def generar_modelo_producto(self, producto_lacteo, datos_historicos):
        """Genera modelo específico para producto lácteo"""
        
        # 1. Clasificar producto y obtener características
        categoria = self.clasificar_producto_lacteo(producto_lacteo)
        caracteristicas = self.obtener_caracteristicas_categoria(categoria)
        
        # 2. Seleccionar distribución base
        distribucion_base = self.seleccionar_distribucion_base(
            datos_historicos, caracteristicas
        )
        
        # 3. Estimar parámetros iniciales
        parametros_base = self.estimar_parametros(datos_historicos, distribucion_base)
        
        # 4. Crear generador con factores específicos
        generador = self.crear_generador_con_factores(
            distribucion_base, parametros_base, producto_lacteo
        )
        
        # 5. Validar modelo generado
        modelo_validado = self.validar_modelo_lacteos(
            generador, datos_historicos, categoria
        )
        
        return modelo_validado
    
    def crear_generador_con_factores(self, distribucion, parametros, producto):
        """Crea generador que considera factores específicos de lácteos"""
        
        def generador_lacteos(fecha_simulacion=None, condiciones_especiales=None):
            # Generar valor base de la distribución
            valor_base = self.generar_valor_distribucion(distribucion, parametros)
            
            # Aplicar factores específicos de lácteos
            factor_total = 1.0
            
            # Factor temperatura (para productos sensibles al clima)
            if producto.categoria in ['helados', 'bebidas_frias']:
                factor_total *= self.factores_lacteos['temperatura'].calcular(
                    fecha_simulacion
                )
            
            # Factor estacionalidad
            factor_total *= self.factores_lacteos['estacionalidad'].calcular(
                producto, fecha_simulacion
            )
            
            # Factor perecibilidad (días hasta vencimiento)
            if hasattr(producto, 'vida_util_dias') and producto.vida_util_dias <= 7:
                factor_total *= self.factores_lacteos['perecibilidad'].calcular(
                    producto
                )
            
            # Factor eventos especiales
            if condiciones_especiales and 'evento' in condiciones_especiales:
                factor_total *= self.factores_lacteos['eventos'].calcular(
                    condiciones_especiales['evento'], producto
                )
            
            # Factor promociones activas
            if condiciones_especiales and 'promocion' in condiciones_especiales:
                factor_total *= self.factores_lacteos['promociones'].calcular(
                    condiciones_especiales['promocion']
                )
            
            # Aplicar factor total y asegurar valor no negativo
            demanda_final = max(0, valor_base * factor_total)
            
            return {
                'demanda': demanda_final,
                'valor_base': valor_base,
                'factor_aplicado': factor_total,
                'factores_detalle': {
                    'temperatura': self.factores_lacteos['temperatura'].ultimo_factor,
                    'estacionalidad': self.factores_lacteos['estacionalidad'].ultimo_factor,
                    'perecibilidad': self.factores_lacteos['perecibilidad'].ultimo_factor
                }
            }
        
        return generador_lacteos
    
    def simular_periodo_completo(self, producto, dias=30, escenarios=1000):
        """Simula demanda para un período completo"""
        
        modelo = self.obtener_modelo_activo(producto)
        resultados_simulacion = []
        
        for escenario in range(escenarios):
            demanda_periodo = []
            fecha_actual = datetime.now().date()
            
            for dia in range(dias):
                fecha_simulacion = fecha_actual + timedelta(days=dia)
                
                # Obtener condiciones especiales para el día
                condiciones = self.obtener_condiciones_dia(fecha_simulacion, producto)
                
                # Generar demanda para el día
                resultado_dia = modelo.generar_demanda(fecha_simulacion, condiciones)
                demanda_periodo.append(resultado_dia)
            
            resultados_simulacion.append(demanda_periodo)
        
        return self.analizar_resultados_simulacion(resultados_simulacion)

class FactorTemperatura:
    def calcular(self, fecha):
        """Calcula factor basado en temperatura ambiente"""
        temperatura = self.obtener_temperatura_historica(fecha)
        
        # Factor lineal: mayor temperatura = mayor demanda de productos fríos
        if temperatura < 15:
            factor = 0.8
        elif temperatura < 25:
            factor = 1.0
        elif temperatura < 35:
            factor = 1.3
        else:
            factor = 1.5
        
        self.ultimo_factor = factor
        return factor

class FactorEstacionalidad:
    def __init__(self):
        self.patrones_estacionales = {
            'helados': {
                'verano': 2.0, 'otoño': 1.2, 'invierno': 0.6, 'primavera': 1.4
            },
            'quesos_especiales': {
                'navidad': 2.5, 'año_nuevo': 2.0, 'normal': 1.0
            },
            'leche_escolar': {
                'periodo_escolar': 1.3, 'vacaciones': 0.7
            }
        }
    
    def calcular(self, producto, fecha):
        """Calcula factor estacional específico por producto"""
        categoria = producto.categoria
        
        if categoria in self.patrones_estacionales:
            estacion = self.determinar_estacion_o_periodo(fecha)
            factor = self.patrones_estacionales[categoria].get(estacion, 1.0)
        else:
            factor = 1.0
        
        self.ultimo_factor = factor
        return factor

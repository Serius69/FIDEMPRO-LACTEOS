🗂️ Estructura Completa de preview_data

Basado en el return statement de prepare_preview_data() (líneas 260-296):

📊 Datos Principales
'business': Dict Información de la empresa (nombre, ubicación, tipo, etc.)
'products_preview': List[Dict] Lista de productos con métricas y categorías
'areas_preview': List[Dict] Áreas con relaciones y benchmarks
'variable_preview': List Lista completa de variables
'variables_by_type': Dict Variables organizadas por tipo (exógenas, estado, endógenas)
'equation_preview': List Lista de ecuaciones del sistema
🔧 Datos de Simulación
'questionary_preview': List Datos de cuestionarios
'question_preview': List[Dict] Preguntas con respuestas de ejemplo por producto
'simulations_preview': Dict Simulaciones organizadas por producto (leche, queso, yogur, etc.)
'simulate_preview': Dict Simulación de ejemplo individual
'pdf_preview': List Datos de configuración PDF
'recommendations_preview': List Datos de recomendaciones financieras
📈 Datos Adicionales
'demand_example': Dict Ejemplos de demanda por producto (valores fijos de 30 días)
'demand_configurations_preview': Dict Configuraciones de demanda con base_demand, seasonality, etc.
'result_simulation_preview': Dict Resultados de simulación con ROI, márgenes, intervalos de confianza
'summary_stats': Dict Estadísticas resumen (totales de productos, áreas, variables, etc.)
'questionary_results_preview': Dict Respuestas de cuestionarios organizadas por producto
